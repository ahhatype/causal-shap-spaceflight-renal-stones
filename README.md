# Causal SHAP: Spaceflight-Induced Renal Stones

Exploring causal inference and SHAP (SHapley Additive exPlanations) methods to
understand risk factors for renal (kidney) stone formation associated with
spaceflight.

## Status

Early scaffolding — code, data, and documentation to come.
